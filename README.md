# OPS_JOB

대학생이 자신의 경험과 역량을 바탕으로 적합한 직무를 탐색하고 진로를 준비할 수 있도록 돕는 직무연결 서비스입니다.

## 프로젝트 소개

진로를 탐색할 때는 관심 있는 직무가 무엇인지 알아보는 것뿐 아니라, 그 직무에 필요한 역량과 현재의 경험을 비교하고 다음에 무엇을 준비할지 파악하는 과정이 필요합니다. OPS_JOB은 경험 기록에 포함된 역량 태그를 직무별 요구 역량과 비교해 직무 매칭 결과와 역량 보완 방향을 제시합니다.

현재 프로젝트는 브라우저에서 실행할 수 있는 독립적인 직무연결 화면입니다. 경험 기록 입력이나 다른 팀 서비스와의 통합은 포함되어 있지 않으며, 저장소 어댑터를 통해 브라우저 저장 데이터 또는 호스트 서비스의 데이터를 읽도록 구성되어 있습니다.

## 주요 기능

### 직무 매칭

- 경험 기록에 포함된 역량 태그 수와 직무별 필요 수준을 비교합니다.
- 태그별 충족도를 계산해 직무별 매칭률을 표시하고, 매칭률이 높은 순으로 정렬합니다.
- 사용자 유형이 1인 경우 테스트 임시 관심 태그도 매칭에 반영합니다. 이 태그는 기록 1개에 해당하는 가중치로 계산되며, 경험 기록이 늘수록 비중이 줄어듭니다.

### 부족 역량 분석

- 매칭 상위 직무 중 분석할 직무를 선택할 수 있습니다.
- 선택한 직무의 필요 수준과 태그가 포함된 경험 기록 수를 표와 레이더 차트로 비교합니다.
- 역량별 충족 상태와 강점 역량의 근거 경험을 표시합니다.
- 목표 직무는 사용자가 직접 설정한 경우에만 저장합니다.

### 역량 보완 추천

- 선택 직무에서 충족도가 가장 낮은 역량을 기준으로 관련 공모전 예시와 체험 미션 예시를 표시합니다.
- 공모전이나 미션 데이터는 교체 가능한 정적 예시이며, 실제 공고를 수집하거나 최신 정보를 제공하지 않습니다.

### 직무 탐색

- 직무별 설명, 필요 역량, 주요 업무, 관련 학과·자격 예시, 준비 활동을 카드로 안내합니다.
- 직무 정보는 프로젝트에 포함된 정적 데이터이며 외부 기관의 최신 정보와 연동되어 있지 않습니다.

## 사용 기술

| 기술 | 사용처 |
| --- | --- |
| HTML | 독립 실행 페이지와 화면 구조 |
| CSS | 반응형 레이아웃 및 직무연결 화면 스타일 |
| JavaScript | 직무 데이터 처리, 매칭·분석, 화면 렌더링, 브라우저 저장소 연동 |
| localStorage | 독립 실행용 사용자 정보와 경험 기록 저장 |
| Chart.js 4.4.7 | 역량 비교 레이더 차트 |

Chart.js는 `index.html`에서 jsDelivr CDN으로 불러옵니다. 차트 기능을 사용하려면 인터넷 연결이 필요합니다. 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 프로젝트 구조

```text
OPS_JOB/
├── README.md
├── index.html
├── job-connection.css
├── job-connection.js
├── common/
│   └── storage.js
└── data/
    ├── contests.js
    ├── jobs.js
    └── missions.js
```

| 파일 | 역할 |
| --- | --- |
| `index.html` | 스타일시트, 데이터, 저장 어댑터, Chart.js, 화면 스크립트를 순서대로 불러오는 독립 호스트 페이지 |
| `job-connection.css` | 직무연결 화면의 레이아웃과 반응형 스타일 |
| `job-connection.js` | 직무 매칭, 역량 분석, 추천, 직무 탐색 카드 렌더링과 화면 이벤트 처리 |
| `common/storage.js` | `localStorage` 기반 사용자 정보와 경험 기록 어댑터 |
| `data/jobs.js` | 직무 설명, 필요 역량, 업무, 준비 활동 및 관련 정보 예시 |
| `data/contests.js` | 역량별 공모전 추천용 정적 예시 데이터 |
| `data/missions.js` | 역량별 체험 미션용 정적 예시 데이터 |

## 실행 방법

### 방법 1: HTML 파일 직접 열기

1. 프로젝트 폴더에서 `index.html`을 찾습니다.
2. 파일을 Chrome 등 웹 브라우저에서 엽니다.
3. 레이더 차트가 표시되지 않으면 인터넷 연결과 Chart.js CDN 접근을 확인합니다.

### 방법 2: 로컬 HTTP 서버 사용

Python이 설치되어 있다면 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 서버는 선택 사항이며, 의존성 설치나 빌드 과정은 없습니다.

## 데이터 및 구현 현황

### 현재 구현된 내용

- HTML 페이지에서 독립적으로 실행되는 직무연결 화면
- 경험 태그와 직무 필요 수준을 사용한 매칭률 계산
- 부족 역량 표, 상태 표시, 레이더 차트 및 보완 추천 카드
- 목표 직무 저장, 직무 탐색 카드
- 저장 어댑터를 통한 사용자 정보·경험 기록 읽기와 목표 직무 저장
- 브라우저 `localStorage`의 `user`, `records` 키 사용. 이전 독립 실행 데이터인 `selfdev.user`, `selfdev.records`도 새 키가 없을 때 읽을 수 있습니다.

### 예시 데이터 및 미연동 항목

- `data/jobs.js`의 직무 설명, 업무, 학과, 자격 및 준비 활동은 프로젝트 내 예시 데이터입니다.
- `data/contests.js`와 `data/missions.js`는 교체 가능한 정적 예시 데이터입니다. 실제 공모전 공고의 검색·수집·갱신 기능은 구현되어 있지 않습니다.
- 커리어넷 오픈API는 연결되어 있지 않습니다.
- 경험 기록 입력 화면은 포함되어 있지 않습니다. 독립 실행에서는 `localStorage`에 저장된 데이터를 사용하며, 실제 서비스에 통합할 때는 기존 데이터 저장소에 맞는 어댑터를 전달해야 합니다.
- 경험 꺼내기 및 STAR 정리 버튼은 `selfdev:navigate` 이벤트를 발생시킵니다. 이 프로젝트 자체에는 해당 화면으로 연결하는 라우터가 없으므로 호스트 서비스에서 이벤트를 연결해야 합니다.

## 호스트 서비스에 통합하기

`index.html`을 참고해 직무 데이터와 저장 어댑터를 먼저 로드한 뒤 `job-connection.js`를 불러옵니다. 화면을 표시할 요소에 `OPSJOB.mountJobConnection(root, storageApi)`를 호출합니다. 전달하는 저장 어댑터는 `getUser()`, `getRecords()`, `getTagCounts()`, `saveUser(user)` 함수를 제공해야 합니다.

반환된 인스턴스의 `refresh()`로 저장 데이터 변경 내용을 다시 표시할 수 있으며, 화면을 제거할 때 `destroy()`를 호출합니다. 실제 경험 꺼내기·STAR 화면 이동은 `selfdev:navigate` 이벤트 수신부에서 연결해야 합니다.
